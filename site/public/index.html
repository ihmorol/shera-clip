SET UP YOUR DESK

Connect your computer.

Local companion

The companion downloads and processes video locally. Start it on this computer, then enter the pairing code printed in its terminal.

First-time setup

Install Python 3.12+ and FFmpeg (with ffprobe and libass). Download and extract the companion, then run these commands in its folder:

python -m pip install -e .
python -m shera

Add your OpenRouter key to the companion’s .env. Your key stays on this computer. The site does not receive it.
